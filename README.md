#### 🛠 What I build

| Project | What it is | Stack |
|---|---|---|
| [**Syllabus RAG Search**](https://github.com/kyoto-kaira/syllabus-search-RAG) | RAG system that searches and summarizes Kyoto University course syllabi. I led the experiments and the retriever implementation and wrote the technical article. | Python · LLM embeddings · RAG |
| **Agentic Timetable AI** | An LLM agent that turns vague course preferences into a full-semester timetable under complex constraints. Built as the follow-up to the RAG project. | Python · LLM agents |
| [**Osarai GO**](https://github.com/KinuGra/osarai-go) | Terminal TUI that turns the "I think I get it" feeling about AI-generated code into understanding: review your own code right in the dev flow, like `git commit`. | Go · Cobra · Bubble Tea · SQLite · LLM |
| **YOUR ISLAND** | Turns saved social-media inspiration into one small action a day on a 3D island. Passed document screening (~3× competition) at the DevFest GDGoC Japan Hackathon and pitched at the Osaka venue. | Gemini · Firebase (Functions / Firestore / Auth) · 3D |
| [**salmonAI**](https://github.com/KinuGra/salmon-ai) | Time-blocking app you reflect on together with AI. Built at GDG on Campus 2026. | Go · Python · LLM |
| [**ActBuddy**](https://github.com/KinuGra/actbuddy-proto) | Behavior-support app built on time-blocking and a buddy system: it changes your environment instead of relying on willpower. | Next.js · TypeScript · Go |
| **Multi-agent RL with 3D KaiRA-kun** | Trained a 3D character in a simulated space. I modeled the character and trained agents at several difficulty levels. | Unity · Reinforcement learning · Blender |
